Writing Assistant Support

For bugs, unexpected edits, MCP connection problems, privacy questions, or plugin-package issues, contact the developer through the Writing Assistant repository issue tracker.

Open a support request on GitHub.

When reporting a writing-quality problem, include a minimal non-sensitive example when possible. Do not post private drafts, credentials, API keys, or confidential source material in a public issue.

For a security-sensitive report, do not include exploit details or secrets in a public issue. Contact the repository owner through the contact methods on the public GitHub profile.
