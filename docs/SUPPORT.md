# Writing Assistant support

For bugs, unexpected edits, MCP connection problems, privacy questions, or plugin-package issues, open an issue in this repository:

https://github.com/mattlane66/Writing_Assistant/issues

When reporting a writing-quality problem, include a minimal non-sensitive example when possible. Do not post private drafts, credentials, API keys, or confidential source material in a public issue.

For security-sensitive reports, do not include exploit details or secrets in a public issue. Contact the repository owner through the contact methods on the public GitHub profile.
