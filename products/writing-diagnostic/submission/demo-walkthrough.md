# Recording guide

Record the packaged version inside ChatGPT or Codex after connecting its actual endpoint. The standalone preview is useful for checking controls, but it does not replace the installed-host demonstration.

1. Show Writing Diagnostic selected and version 1.2.0 installed. Keep unrelated private information and credentials off screen.
2. Run the universal-claim prompt from `review-cases.json`. Show the real returned passage, verdict, thinking question, and repair bank.
3. Select a primitive filter, inspect a marked phrase, choose Keep it or a repair direction, and use Revise with these decisions to show the host conversation receiving the choice.
4. Run the repeated-quote prompt. Select each occurrence and show that the right finding opens.
5. Run the whole-passage reasoning prompt. Open the whole check and show the causal-evidence question.
6. Run the passive and bounded-comparison prompts. Show calibrated treatment and Keep it when the model supplies a pass.
7. Run the three out-of-scope prompts. Show the actual limits without fabricated retrieval, publishing, or fact certification.
8. Replay the recording. Verify readable prompts/results, actual interactions, and successful playback. Host it with reviewer access and add its real URL through the public-settings step.

This guide records no result and makes no claim that the installed-host cases have already passed.
